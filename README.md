## The word

`placeholder`

The word an ex would use to describe me. I was never the destination —
just the stand-in filling the gap until the real thing came along.
Vivid, specific, and painfully honest.

## How it works

`main.py` writes exactly one word — `placeholder` — followed by a
newline to `/output/entry.txt`, then validates the file: exactly one
word, no spaces, no control characters.

Run it:

```sh
python3 main.py
```
